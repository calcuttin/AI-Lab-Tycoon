# Upgrade photography

All 21 upgrade types have distinct inspection artwork. Eighteen new photographs were generated once each with the built-in image generation tool on 2026-09-08. The model version is not exposed by the tool. Exact prompts, source paths, and web outputs are indexed in `manifest.json`; versioned PNGs and prompt files are preserved here. Basic desks, coffee corner, and storage closet reuse the existing `art/garage-details/` photographs and prompts. No earlier assets were replaced.

Web images live in `public/images/upgrades/` at 640px and 1600px, JPEG quality 80. Images are requested responsively and thumbnails lazy-load.

Art direction: natural photographic Bay Area startup interiors, warm afternoon light, tangible wear and materials, sensible furniture spacing. Practical cooler lighting distinguishes the server room. No people were requested. Some generated equipment/packaging marks remain at small scale.

One image represents each upgrade type across its levels and compatible buildings. The live level and furnishing data remain authoritative; these are photographic interpretations rather than literal renders of the floor plan. The retained 3D layout still provides the spatial overview.

Preview all images locally at `http://127.0.0.1:5174/?garage-study=1#upgrades`, or select Browse all upgrades in the office. Previewing never purchases equipment.
